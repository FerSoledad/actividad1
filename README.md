# Paint.py

Programa realizado en Python utilizando Turtle para dibujar figuras geométricas.

# Modificaciones realizadas

Se realizaron las siguientes mejoras al código inicial:

- Se agregó un nuevo color al programa.
- Se implementó la función para dibujar círculos.
- Se implementó la función para dibujar rectángulos.
- Se implementó la función para dibujar triángulos.

# Figuras disponibles

- Línea
- Cuadrado
- Círculo
- Rectángulo
- Triángulo

# Ejecución

Ejecutar el programa con:

python3 paint.py
